简易资源管理系统。定位：提供简易方便的资源热更管理功能。例如：配置表，简单，小，更新频繁。 注意：由于定位是轻便情况下使用，因此没有过渡考虑性能提升问题。 注意：没有资源的对象池复用和引用计数。

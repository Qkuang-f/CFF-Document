WaitForTaskEnd(Task, CancellationTokenSource, int)

等待任务结束（成功或失败）。 超时后可选择对提供的 CancellationTokenSource 调用 Cancel() 发出协作取消信号，然后停止等待。 注意：若任务内部未检查 token，则无法强制终止，只是放弃继续等待。 注意：task和cts需要自己using释放资源。

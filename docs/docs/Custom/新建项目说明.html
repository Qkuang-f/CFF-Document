新建项目说明

安装依赖

  1. 安装NuGet：通过git url安装此package git@github.com:GlitchEnzo/NuGetForUnity.git?path=/src/NuGetForUnity
  2. 安装依赖包（Nuget）
    1. 搜索安装Newtonsoft.Json
    2. 搜索安装MemoryPack
  3. 安装Addressable：在Unity的Pacak中安装Addressable。

可选依赖

  1. Other文件夹中的导出源码文件属于辅助文件，如遇报错，或不想用可以直接删除。
  2. DoTween：有一些常用的动画脚本是依赖DoTween。如果不需要此脚本，可以在Other文件夹中找到，并删除。

导出dll

  1. 生成最新的DLL：菜单CFF/Tool/ExportDll/Generate With CleanBuildCache
  2. 收集生成的DLL: 菜单CFF/Tool/ExportDll/Collect CFF Files
  3. 在搜集结束后，有弹窗提示打开收集的文件夹。打开文件夹，把CFF文件夹内的文件Copy到新项目中。

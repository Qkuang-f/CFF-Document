DLL说明

DLL之间没有等级、只有相互依赖关系。但要注意不要循环依赖。

三方库：三方库的使用遵循"宏分割"准则。

模块/系统划分表

表记录一个模块/系统分散于net库还是unity程序集中，使用时是限unity客户端使用还是双端使用？

通常，代码双端使用，则代码定义在net库中。若代码仅限客户端中，则代码定义在unity程序集中。

划分逻辑：

  1. 双端代码，归net库；客户端代码，归unity程序集。
    1. 注：xx库在框架中通常指net库，xx程序集在本框架中通常指unity程序集。
  2. 库
    1. any: 表示任意的库。
    2. Base：表示基础逻辑库(与游戏无关)。
    3. Core: 表示游戏的核心逻辑库。
    4. Math：表示数学库，内含数学计算、自定义数据结构。
    5. Game：表示游戏的程序集。

dll划分逻辑：

  1. 最简单的划分依据：应用/游戏-双端/游戏-细分/游戏-服务器/游戏客户端。
    1. CFF: 应用/游戏都可用
    2. CFF.Core: 游戏双端都可用
    3. CFF.Core.ACT: 双端可用，且是特定的ACT类型游戏。（细分游戏）
    4. CFF.Server: 服务器可用
    5. CFF.Game: Unity客户端可用
    6. CFF.xxx: 其他类型的库，如math等。
    7. 注：只要unity导出dll方便，归net库或unity程序集都一样。

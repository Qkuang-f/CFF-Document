FSM

Unity中通过ScriptObj重写了FSM的配置。ScriptObj的配置，只读，不允许修改。Runtime部分的逻辑，额外开发一套代码。

原因：ScriptObj无法通过Unity的Instantiate函数进行深度克隆。因此需要只读才能做好共享模式，避免一个修改，影响全部。

技巧

  1. FSMStateRuntime的frameMax是最大帧数，而currentframe从0开始，默认-1，因此frameMax=30时，不会有30的帧号。
  2. FSMParamaBaseRuntime的开始帧和结束帧是[start,end]，左右含。因此，如果Param的帧范围包含state的帧长度，那么paramRuntime在update循环时只会触发一次Enter。
    1. 在播放动画时，希望Enter时，动画播放只一次时有用。
